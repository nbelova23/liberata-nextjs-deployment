# Exercise 4: Layouts in Next.js

## Why This Exercise Matters for Students 🎯

### **Design Systems Thinking**
Layouts are like the architectural blueprints of web applications. Just as university campuses have consistent design elements across buildings, web applications need consistent layouts across pages. This exercise teaches you to think systematically about user experience.

### **Efficiency and Consistency**
Instead of copying and pasting headers and footers on every page, you'll learn to create reusable layouts. This is the same principle used for course syllabi templates or administrative forms - create once, use everywhere.

### **Context API Integration**
You'll combine React's Context API with Next.js layouts to manage global state (like themes). This is crucial for building applications where user preferences persist across different pages.

## Technical Concepts (Explained Simply) 🔧

### **Layout Components**
Think of layouts like building templates:
- **Main Layout**: The basic structure (like a standard building design)
- **Specialized Layouts**: Variations for specific needs (like lab buildings vs. residential)
- **Nested Layouts**: Layouts within layouts (like floors within buildings)

### **Context API for Global State**
Imagine a university ID card system:
- Your ID card works across campus (global state)
- It remembers your meal plan, access permissions, etc.
- Context API works similarly - it shares data across your entire app

### **Theme Management**
Like a website having both light and dark modes:
- User selects their preference once
- It applies to every page they visit
- The choice persists across browser sessions
