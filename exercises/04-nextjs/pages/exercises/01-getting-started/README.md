# Exercise 1: Getting Started with Next.js

## Why This Exercise Is Important 🎯

### **Foundation for Modern Web Development**
This exercise introduces you to Next.js, one of the most popular React frameworks used by companies like Netflix, TikTok, and Vercel. Understanding Next.js is crucial for modern web development careers.

### **File-Based Routing Mastery**
Unlike traditional React apps where you manually configure routes, Next.js uses file-based routing. This exercise teaches you:
- How file structure directly maps to URL routes
- The power of convention over configuration
- How to create pages without complex routing setup

### **Component Reusability in Practice**
You'll learn to create reusable components (Button, Card) that can be used across your entire application. This is essential for:
- **Maintainable Code**: Change once, update everywhere
- **Consistent UI**: Same look and feel across pages
- **Developer Productivity**: Build faster with reusable pieces

### **Tailwind CSS Integration**
This exercise introduces Tailwind CSS styling within Next.js, teaching you:
- Utility-first CSS approach
- Responsive design patterns
- How to style components efficiently

### **Hot Reloading Experience**
You'll experience Next.js's incredible developer experience with instant updates when you save files - a game-changer for productivity.

## Real-World Applications 🌍

### **E-commerce Websites**
- Product pages with reusable Card components
- Navigation between product listings and details
- Consistent Button styling across the site

### **Corporate Websites**
- About pages with company information
- Contact forms with reusable form components
- Consistent branding through shared components

### **Portfolio Sites**
- Project showcase pages
- About/Contact navigation
- Reusable project cards

## Skills You'll Gain 💪

1. **Next.js Fundamentals**: Understanding the framework that powers modern web apps
2. **Component Architecture**: Building reusable UI components
3. **File-Based Routing**: Navigation without complex configuration
4. **Tailwind CSS**: Modern utility-first styling
5. **Developer Experience**: Working with hot reloading and instant feedback

## Career Relevance 💼

- **High Demand**: Next.js developers are in high demand with competitive salaries
- **Industry Standard**: Used by major companies for production applications
- **Full-Stack Ready**: Next.js enables both frontend and backend development
- **Performance Focus**: Built-in optimizations for fast, SEO-friendly websites

## What You'll Build 🛠️

By the end of this exercise, you'll have:
- A working Next.js application with multiple pages
- Reusable Button and Card components
- Navigation between pages using Next.js Link
- Styled components using Tailwind CSS
- Understanding of Next.js project structure

This foundation will prepare you for more advanced Next.js concepts like data fetching, dynamic routes, and deployment.
