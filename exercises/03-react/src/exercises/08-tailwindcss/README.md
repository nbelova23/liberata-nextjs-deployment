## Technical Concepts (Explained Simply) 🔧

### **Utility Classes**
Small, single-purpose classes that do one thing:
- **Spacing**: `p-4` (padding), `m-2` (margin), `space-x-4` (gap between items)
- **Colors**: `bg-blue-500` (background), `text-red-600` (text color)
- **Layout**: `flex` (flexbox), `grid` (CSS grid), `block` (display block)
- **Typography**: `text-lg` (font size), `font-bold` (font weight)

### **Responsive Design**
Mobile-first approach with breakpoint prefixes:
- **Mobile First**: Base styles apply to mobile, then override for larger screens
- **Breakpoints**: `sm:`, `md:`, `lg:`, `xl:` prefixes for different screen sizes
- **Responsive Utilities**: `md:text-lg` (large text on medium screens and up)
- **Container**: Responsive container with max-widths at each breakpoint

### **Component Patterns**
Common patterns for styling React components:
- **Conditional Classes**: Using template literals for dynamic styling
- **Component Variants**: Different styles for different component states
- **Composition**: Combining utilities to create complex designs
- **Reusability**: Creating consistent patterns across components
