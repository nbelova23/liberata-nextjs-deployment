# Introduction to Liberata Onboarding

## Welcome to Liberata!

Welcome to the Liberata Onboarding Program! This guide is specifically designed for Duke University undergraduate students who are new to web development or the Liberata tech stack. Our goal is to provide you with a comprehensive, step-by-step introduction to modern web development tools and practices.

## What is Liberata?

Liberata is an open-source project that aims to [brief description of Liberata's mission and goals]. As a contributor, you'll be working with cutting-edge web technologies and learning industry-standard development practices.

## Why This Onboarding?

We understand that diving into a new tech stack can be overwhelming, especially when you're new to web development. This onboarding program is designed to:

1. **Build Confidence**: Start with the basics and gradually progress to more complex concepts
2. **Hands-on Learning**: Learn by doing through practical labs and exercises
3. **Industry Best Practices**: Understand modern development workflows and tools
4. **Real-world Experience**: Work with the same tools and processes used in professional development

## What You'll Learn

### 1. Development Fundamentals
- Git version control
- Command-line basics
- Code editors and IDEs
- Package management

### 2. Web Development Core
- TypeScript fundamentals
- React component development
- Next.js framework
- API development

### 3. Cloud & Infrastructure
- Cloudflare Workers
- Supabase database
- Redis caching
- Object storage

### 4. Development Workflow
- Branch management
- Pull requests
- Code review process
- DRI (Directly Responsible Individual) culture

## How to Use This Repository

This repository is organized into two main sections:

1. **Documentation** (`/docs`): Essential reading and reference materials
2. **Exercises** (`/exercises`): Hands-on learning modules for each technology

### Learning Path

1. Start with the [Prerequisites](./prerequisites.md) to set up your development environment
2. Create necessary accounts as described in [Accounts & Setup](./accounts.md)
3. Begin with the Git Basics exercise in `/exercises/01-git-basics/`
4. Progress through the exercises in order
5. Use the [Glossary](./glossary.md) when you encounter unfamiliar terms

## Getting Help

- **Office Hours**: Regular sessions where you can ask questions and get help
- **Documentation**: Comprehensive guides in the `/docs` directory
- **Community**: Connect with other students and mentors
- **Issues**: Use GitHub issues to report problems or suggest improvements
